# RoomCheck Privacy Policy

Effective date: August 10, 2026

RoomCheck helps users check scheduled classroom availability from timetable
data they choose to import. The app is designed to work locally on the user’s
device.

## Data RoomCheck handles

RoomCheck may process:

- timetable documents selected by the user;
- classroom names;
- departments and academic levels;
- course codes and optional course titles;
- weekdays and class times; and
- RoomCheck backup files deliberately created or restored by the user.

RoomCheck does not require a user account. It does not ask for a name, email
address, phone number or precise location.

## How data is used

Selected timetable data is used only to:

- determine which classrooms are scheduled to be free;
- show the schedule for a selected department and level;
- manage imported timetable documents; and
- create or restore a user-requested backup.

## Local storage

Imported documents and structured timetable records are stored in the app’s
private storage on the device. RoomCheck has no timetable-data server and does
not automatically upload this information.

Uninstalling the app may remove its local data. Users should export a backup
before uninstalling or changing devices.

## Sharing and backups

RoomCheck opens the device share sheet only after the user selects Export
RoomCheck Backup. The user chooses the destination and recipient.

A RoomCheck JSON backup contains structured timetable information. It does not
contain the original XLSX, CSV or timetable image files. Users should store
backup files privately.

## Analytics, advertising and tracking

RoomCheck does not include advertising, behavioral analytics, cross-app
tracking or location tracking.

Development copies opened through Expo Go may use Expo’s development services
to load the application bundle. That development activity is separate from
RoomCheck’s timetable-data handling.

## Device permissions

RoomCheck uses the system document picker when the user chooses to import a
timetable or restore a backup. It does not scan unrelated device files.

The system share sheet is used when the user exports a backup. RoomCheck does
not choose where the backup is sent.

## Data deletion

Users can:

- remove one imported timetable document;
- remove one manually entered image timetable row;
- clear every imported document and timetable row; or
- uninstall RoomCheck to remove its app storage, subject to the device
  operating system’s backup and retention behavior.

## Children’s privacy

RoomCheck is an educational utility and does not knowingly collect personal
information from children or adults. Institutions deploying the app remain
responsible for ensuring that timetable documents do not contain unnecessary
personal information.

## Security

RoomCheck limits data exposure by processing timetable information locally.
No system can guarantee absolute security, so users should protect their
devices and backup files.

## Changes to this policy

If a future version adds accounts, cloud synchronization, automatic cloud OCR,
analytics or another external data service, this policy and the app-store data
declarations must be updated before that version is released.

## Contact

Privacy questions should be sent through the developer contact address shown
on RoomCheck’s official app-store listing.
